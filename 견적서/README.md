# 견적서 자동화

제품 DB(원가·사진)를 등록해 두고, 견적번호·수신·현장과 모델명만 입력하면 제품 사진이 들어간 엑셀 견적서를 만드는 HTML 프로그램.

## 쓰는 파일

- **`견적서_자동화.html`** — 이 파일 하나만 내려받아 크롬/엣지에서 열면 된다. 엑셀 라이브러리가 들어 있어 인터넷 없이도 동작한다.
- 데이터(제품 DB, 견적 대장, 사진)는 그 PC의 브라우저에 저장된다. 다른 PC로 옮기거나 보관할 때는 프로그램의 **설정 · 백업 → 백업 파일 받기**를 쓴다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `src/app.html` | 편집용 원본. 여기만 고친다 (단독으로 열면 엑셀 라이브러리를 인터넷에서 받아 쓴다) |
| `vendor/` | ExcelJS 4.4.0, JSZip 3.10.2 와 라이선스 |
| `build.py` | `src/app.html` + `vendor/` → `견적서_자동화.html` |

## 고친 뒤 배포 파일 만들기

```
python3 견적서/build.py
```
